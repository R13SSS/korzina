# Корзина

Список покупок с ценами, картинками и рецептами. Открывается с телефона без VPN, работает и офлайн.

- **Сайт:** https://r13sss.github.io/korzina/ (на iPhone: Safari → «Поделиться» → «На экран „Домой“»).
- **Запросы:** на сайте поле «Что ещё купить?» создаёт issue в этом репозитории. Открытые issues — это очередь: Claude находит цены, обновляет корзину и закрывает их.
- **Данные:** `data/cart.json` — списки (новый первым), товары и рецепты. Картинки товаров — в `img/`.
- **Виджет:** `scriptable/korzina-widget.js` — скрипт для приложения Scriptable.
- **Офлайн-файл:** `python3 build_offline.py korzina.html` собирает один HTML со всем внутри.
