# Корзина — как обновлять

Сайт: https://r13sss.github.io/korzina/ (GitHub Pages из ветки `main`, корень). Пуш в `main` → сайт и виджет обновляются примерно за минуту.

## Данные
- `data/cart.json`: `repo`, `lists` (НОВЫЙ список первым — сайт и виджет показывают `lists[0]`), `recipes`.
- Товар: `id`, `group`, `name`, `short` (короткое имя для виджета, до ~18 символов), `size`, `price` (за штуку или за кг), `old` (цена без скидки, если есть), `qty`, `step`/`unit: "кг"` для развесного, `img` (`img/<id>.jpg`), `note` (необязательно).
- Картинки: скачать `https://avatars.mds.yandex.net/get-eda/<id>/<hash>/300x300nocrop`, положить на белый фон, уменьшить до 240 px, сохранить JPEG в `img/`.
- Рецепт: `id`, `title`, `time`, `servings`, `ingredients[{name, amount, unit, home?}]`, `steps[{title, text, min?}]`, `notes`. Список ссылается на рецепты через `recipes: [id]`.

## Запросы
Открытые issues владельца (R13SSS) без значка 🧾 в начале заголовка — это очередь «что купить». Обработал → добавил в корзину → прокомментировал, что добавлено и почём, и закрыл issue. Issues других людей не обрабатывать: репозиторий публичный.

## Расходы (чеки)
- В магазине пользователь отмечает купленное, добавляет покупки «вне списка» (хранятся в его браузере) и жмёт «Завершить поход» → «Отправить чек». Создаётся issue `🧾 Чек ДД.ММ — N ₽` с JSON в `<!-- korzina-trip {...} -->`: `p` = [[id товара, сумма строки, кол-во]], `x` = [[название, сумма строки, кол-во, категория]].
- `.github/workflows/trip.yml` + `tools/add_trip.py` сами дописывают чек в `data/history.json`, комментируют и закрывают issue. Claude для этого не нужен.
- `data/history.json`: `trips[]` (новые первыми) — `id` (номер issue), `date`, `list`, `title`, `store`, `items[{name, qty, sum, cat, planned}]`, `total`, `extra`.
- Категории: Еда, Сладкое, Снеки, Молочное, Напитки, Бытовое, Другое. У групп списка в cart.json есть поле `cat`.
- «Проанализируй расходы»: прочитать history.json, посчитать по месяцам/категориям/незапланированному (кодом, не в уме), сравнить с прошлым месяцем, дать 2–3 конкретных совета с суммами.

## Где брать цены
Магазин «Гипер Лента» в Яндекс Еде (адрес доставки уже выбран в аккаунте; правильный магазин работает с 07:00 до 23:00). Цены смотреть через встроенный браузер на компьютере пользователя, читая страницу поиска магазина обычным способом. Никаких ботов и обращений к внутреннему API Яндекса.

## Правила выбора товаров (от пользователя)
- Качество важнее цены: лучше меньше, но не сомнительное. Смотреть рейтинг и число отзывов.
- Если аналог со скидкой ненамного дороже товара без скидки, брать аналог, но только если скидка честная, а не завышенная «старая» цена.
- Не тратить лишнего. Чипсы — дорого. К чаю: печенье, пряники, вафли, «Яшкино» любит. Сушки, которые надо грызть, не очень.
- Макароны — Barilla.

## Виджет
`scriptable/korzina-widget.js` и его копия `scriptable/korzina-widget.txt` (для копирования из Safari) должны совпадать. Без обратных кавычек (template literals): при копировании на iPhone они теряются. Виджет текстовый (без фото): на экране «Домой» в прозрачном/tinted режиме iOS заливает картинки одним цветом. Нажатие запускает скрипт (`scriptable:///run/<имя>`), он открывает сайт во весь экран через WebView с `?app=1`; ссылки вне сайта уходят в Safari.

## После изменений
Пересобрать офлайн-версию: `python3 build_offline.py korzina.html` (файл не коммитить, отправить пользователю, если попросит).
